💡 "사용 게임 많으면 순위에서 밀리지 않나?" — 절반 맞다. 태그는 두 가지 일을 한다

Action처럼 사용률 높은 태그의 값은 기능에 따라 정반대다. 이 구분이 태그 전략의 핵심이다.

  • ① 태그 허브/브라우즈 순위 — Action엔 17,104개가 몰려 신작은 묻힌다. 여기서 Action의 노출 이득은 거의 0. 브라우즈는 인기·평점·출시일순 정렬이지 '태그를 앞에 둔 정도'로 정렬되지 않는다. 그래서 Competitive(369개)·Team-Based(985개)처럼 경쟁작이 적은 태그라야 허브 상위 선점이 가능하다.
  • ② AND 필터 + 추천 매칭 — 유저가 'Action' 필터를 걸면 Action 없는 게임은 통째로 제외된다(Steam 태그 필터 = AND). 디스커버리 큐·추천도 태그 유사도로 매칭하므로, 92%가 가진 장르 태그를 빼면 장르 신호가 약해져 관객 후보에서 누락된다. "안 쓰면 손해"가 바로 이것.

정리 — Action은 순위 경쟁용이 아니라 '기본 포함값(table stakes)'. 모두 갖고 있어 차별화 이득은 없지만 빼면 필터·매칭에서 손해다. 순서는 별개: 허브 순위는 순서 무관, 순서가 주로 좌우하는 건 스토어 캡슐 표시이고 추천 알고리즘은 상위 20개 이웃 중첩을 본다(4장 레버). 따라서 앞 슬롯엔 저경쟁·고관련 태그(Competitive·Team-Based)를 두고, Action·FPS는 반드시 포함하되 1순위일 필요는 없다.

03비어있는·가장 안 쓰는 태그 분석

"거의 안 쓰는 태그"는 둘로 갈린다. ① 무관해서 빔(버림), ② 관련 있는데도 빔 = 노출 기회. PVP 슈터엔 후자가 전략 핵심.

🎯 관련 있는데 비어있음 = 기회 태그

PVP 슈터를 정확히 설명하나 슈터 전체 사용률이 낮다 → 경쟁작이 적어 태그 허브·추천 상위 노출 가능.

  • Competitive — 2.0%(369). 정통 PVP 정체성인데 거의 빔 → 최우선.
  • e-Sports — 1.7%(309). 경쟁 지향 + 초희소.
  • Team-Based — 5.3%(985). 팀 경쟁이면 필수급인데 저경쟁.
  • Tactical — 슈터∩ 9.1%(1,697). CS·R6 하드코어 팬 정조준.
  • Gun Customization — 5.6%(1,043). 총기 커스텀 있으면 하드코어 어필 + 저경쟁.
  • Class-Based · Hero Shooter · Arena Shooter — 캐릭터 없음(확인) + 캐주얼/아레나 축 → 제외.

🗑️ 관련 없어서 비어있음 = 버림

사용률이 낮거나(높아도) 장르와 어긋나 붙이면 잘못된 관객 노출 → 전환율↓.

  • Extraction Shooter — 0.8%(154). 추출 없음(확인) → 제외.
  • Battle Royale — 2.5%(456). BR 모드 없으면 제외.
  • Twin Stick / Bullet Hell / Shoot 'Em Up / Boomer Shooter — 2D 아케이드 슈팅. 수치는 높아도 완전 다른 장르.
  • Singleplayer / Open World / Stealth / PvE — 순수 PVP 코어와 무관.
주의 — 관련 없는 태그는 "빈 슬롯"이 아니라 "마이너스"
Steam은 태그로 추천·디스커버리 큐·태그 검색을 구성한다. 무관한 태그(예: Singleplayer, Shoot 'Em Up)를 넣으면 싱글·슈뮵 유저에게 노출되고, 그들은 클릭·위시리스트를 안 해 CTR·전환율↓ → 알고리즘 평가 하락. 태그는 20개를 채우는 게 아니라 정확히 채우는 게 목적이다.

🔬 검증 — 실제 상위 FPS·슈터 타이틀은 무슨 태그를 쓰나

"사용량 적음 = 기회"는 희소성(레버 ①) 한 축만 본 것. 확실히 하려면 같은 레인 성공작이 그 태그를 실제로 쓰는가(수요 검증)를 봐야 한다. 주요 슈터 9종의 상위 5개 메인 태그(스토어 표시순)를 조회했다.

✅ 희소한데 "쓰인다" = 진짜 기회

사용률은 낮지만(희소성 레버) 경쟁·택티컬 레인 성공작이 실제 채택 → 수요 검증됨. 우리 앞 슬롯 배치의 근거.

  • Competitive (2.0%) — CS2 상위 5, R6·PUBG 보유. 정통 경쟁 핵심.
  • Tactical (9.1%) — R6 상위 5, CS2·EFT·Delta·Hunt·PUBG 보유. 하드코어 팬 직결.
  • Team-Based (5.3%) — Hunt 상위 5, CS2·R6 보유. 팀 경쟁 신호.
  • Gun Customization (5.6%) — EFT 상위 5, Delta 보유. 총기 커스텀.
  • e-Sports(1.7%) — CS2·R6 보유, 단 랭크·리더보드 있을 때만.

🗑️ 희소하지만 "우리 레인이 아님" = 버림

낮은 이유가 기회가 아니라 특정 타이틀 고유 성격이라서. 붙이면 엉뚱한 관객 노출 → 전환율↓.

  • Psychological Horror — EFT 1위지만 그 게임 고유 톤. 무관.
  • Extraction Shooter — Delta·EFT·Hunt 정체성. 추출 없으면 제외.
  • Battle Royale — PUBG·BF6 BR 모드용. 없으면 제외.
  • PvE — HD2 코어. 순수 PvP엔 부적합 → 제외. (협동 Online Co-Op·Co-op은 유지)
🎯 결론 — "사용량 적음"은 필요조건일 뿐
판별: "내 레인 성공작이 그 희소 태그를 쓰는가?" 쓰면(Competitive·Tactical·Team-Based) → 희소성(레버 ①)+검증된 수요를 둘 다 갖춘 진짜 기회. 안 쓰거나 고유 성격이면(Psychological Horror·Western) → 무관한 태그. 즉 희소성은 가중치를, 벤치마크는 '실재 관객' 연결을 검증 — 레버 ③(이웃 중첩)과 직결: 우리 세트가 CS2·R6과 겹칠수록 추천에 함께 노출.
⚠ 시점: 경쟁·택티컬 정체성은 1인칭(CS2·R6), TPS 시점은 HD2·PUBG에서 각각 검증됐으나 "TPS+경쟁 PVP" 조합 상위작은 없다 — 곧 우리 블루오션(3인칭 PVP 975개). 정체성 태그를 Third-Person Shooter와 결합해 빈 조합 선점.

🌊 확정된 공백

Competitive·Tactical·Team-Based를 함께 앞세운 "3인칭·논히어로·경쟁 PVP" 상위작은 없다. 각 태그 관객은 크지만(검증됨) 그 조합 앞자리는 임자가 없음 → 우리가 앉으면 조합 브라우즈·추천 선두. 4장 블루오션(975개)과 일치.

⚠ 단 하나의 경합 지점 — Team-Based
Team-Based 앞자리는 히어로·클래스 슈터(Overwatch·TF2·Marvel Rivals)가 점유 — 관객 겹칠 위험. Third-Person Shooter·Competitive를 함께 걸어 "논히어로 정통 경쟁"임을 상쇄. Gun Customization은 커스텀 깊이 있을 때만.

04결론 — 우리 PVP 슈터 태그 전략

대상: 정통 경쟁형 3인칭(TPS) PVP 슈터 · 아포칼립스 · 캐릭터 없음 — CS2·R6 급 스킬·팀 경쟁 밀도 지향, 캐주얼/아레나 배제. 아래는 태그 슬롯(최대 20) 배치 권장안. (순서보다 상위 20개의 정확성·이웃 중첩이 핵심 — 'Valve 3대 레버' 참고)

② 정확성 무관 태그 배제

③ 이웃 중첩 상위 20개의 겹침

Valve 요지: 상위 20개 태그가 유사 게임 판정을 좌우하며, 순서보다 태그 간 중첩이 중요하다.

적용 → 우리 20개 세트가 ARC Raiders·DARKEST DAYS 등 목표 이웃과 겹치는 정도가 "More Like This"·태그 페이지 노출을 결정 → 의도적으로 겹치게 설계.
⚠ 정정 — "태그 순서"에 대한 오해 (Valve 원문 반영)
Valve 명시: 순서보다 중첩(overlap)이 중요. 앞 순서 = 캡슐 표시에 영향, 추천·유사도 = 상위 20개의 정확성·이웃 중첩. 실무 결론: 순서 미세조정보다 정확(②)·희소(①)·이웃 중첩(③) 20개 선정이 핵심. (경쟁 태그를 앞에 두면 캡슐 첫인상 유리.)

한 줄 결론 (3인칭 아포칼립스 정통 PVP)

핵심 4종(Third-Person Shooter·Shooter·PvP·Multiplayer)으로 노출량을 깔고, 정통 경쟁 태그(Competitive·Tactical·Team-Based·e-Sports)를 앞 슬롯에 올려 CS2·R6 급 하드코어 경쟁 팬을 정조준(Action은 92%라 2군 끝 '기본값'). 세계관은 Post-apocalyptic. 관련성 높고 경쟁작 적어(3인칭 PVP 975개) '노출을 이기는' 축. 반대로 슈뮵·싱글·1인칭(FPS·First-Person)·캐릭터제(Class/Hero)·캐주얼/아레나는 배제해 '3인칭 아포칼립스 하드코어 PVP'를 선명히 유지.

05노출 극대화 — 태그 밖의 레버 (비지빌리티 옵스)

태그는 "누구에게 보이나"를 최적화하는 매칭 레버일 뿐, 트래픽 자체는 만들지 않는다(Valve도 유입량이 아닌 플레이타임·전환을 본다). "가장 높게"는 위시리스트 속도 + 전환 + 이벤트 트리거를 우리 태그 위에 얹을 때 나온다. (태그 택소노미와 인접한 '노출 운영')

① 위시리스트 속도 총량 아님

업계 분석상 최근 48–72h 증가율(속도)이 핵심 — 폭증이 같은 총량보다 강하다(Valve 공식 수치 아님; Valve는 위시리스트를 직접 요소가 아닌 검증 프록시로 규정). 2026 개편으로 Popular Upcoming 문턱 급등(보도상 ~6–7천 → 약 8만+) → 인디엔 닫힘, 실질 경로는 ③으로.

※ 페이지 오픈 스파이크 ≠ 결정적 노출 트리거 — 초기엔 모수가 작고, 노출 창(출시 60일 내·③ Personal Calendar) 밖일 수 있음. 진짜 승부처는 출시 근접 스파이크.
우리 실행 → 스토어 'Coming Soon' 페이지를 일찍 열어 상시 축적(오픈 초기 스파이크는 덤). 속도 스파이크는 트레일러·Next Fest·출시 30–60일 전 구간에 몰아 노출 창과 정렬.
② Steam Next Fest 단일 최대 이벤트

기존 위시리스트를 증폭 — 많이 들고 갈수록 더 얻는다. 페스트 전·첫 48h 증가를 보상, 고유 플레이어 상위 50개 Top Demos가 '승자'.

우리 실행 → F2P도 데모/플레이테스트로 참가. 위시리스트를 들고 들어가 증폭 극대화.
③ Personal Calendar 여기서 태그가 직접 작동

2026 홈 개편 기본 노출면(2025-10 Steam Labs #16 → 기본 탑재). 플레이타임 유사도·위시리스트 속도·장르 친화도(협업 필터링·일 갱신)로 유사 코호트에 출시 60일 내 예정작 매칭. 최소 위시리스트 없음 → Popular Upcoming의 인디 실질 대안.

우리 실행 → 태그 세트(TPS+Competitive+Tactical, ARC Raiders·DARKEST DAYS 중첩)가 올바른 코호트 매칭으로 전환 → 순위↑. 출시일 30–60일 전 확정으로 Calendar 창 정렬.
④ Launch Visibility Round 출시 순간

출시 시 New Releases 큐 → New & Trending → Top Sellers → 메인 캡슐로 상승. Valve는 실제 구매를 '골드 스탠더드'로 우선.

우리 실행 → F2P는 설치·동접·플레이타임으로 치환. 정확한 태그 관객일수록 위시리스트→설치→플레이 전환↑ → 라운드 승리.
⑤ 리뷰 억제 회피 + 모멘텀

Mixed(40%) 이상이면 리뷰 점수는 노출 요소 아님, 40% 밑이면 노출 감소. 총점보다 최근 모멘텀·전환 기여가 중요.

우리 실행 → 출시 초기 리뷰 볼륨 확보 + 40% 위 유지(가능하면 Very Positive).
⑥ Update Visibility Rounds 라이브서비스 강점

대형 업데이트·신콘텐츠·DLC 시 전용 프론트페이지 슬롯으로 라이브러리·위시리스트 보유자에게 노출.

우리 실행 → F2P 라이브 슈터의 정기 시즌·패치 케이던스로 이 슬롯을 반복 확보.

06방법론 & 데이터 소스

데이터 근거는 요청대로 Steam / SteamDB / SteamCharts만 사용했다.

집계 방식 — 태그 공동출현(co-occurrence)

슈터 모집단을 고정하고 각 후보 태그가 그 안 몇 개 게임에 함께 붙는지를 셌다. Steam 스토어 검색의 카운트 엔드포인트를 직접 조회(태그 필터 = AND).

store.steampowered.com/search/results/?tags={슈터ID},{후보태그ID}&category1=998&json=1 → 응답 JSON의 total_count

  • 기준 모집단: Shooter(ID 1774) = 18,587개. 가장 넓은 슈터 우산 태그로 FPS·TPS·Tactical·Survival을 모두 포괄.
  • 사용률(%) = (기준 ∩ 후보 태그 게임 수) ÷ 18,587. 즉 "슈터 게임 100개 중 이 태그를 쓰는 게임 수".
  • 범위: category1=998(게임만, DLC·소프트웨어·OST 제외).
  • 태그명↔ID 매핑은 Steam 공식 store.steampowered.com/tagdata/populartags/english에서 취득.
데이터 한계 (투명 고지)
① SteamDB /tags/·SteamCharts 페이지는 Cloudflare 봇 차단(403)이라 카운트는 Steam 스토어 공식 엔드포인트를 1차로 사용(SteamDB ID 체계와 교차검증). ② "Shooter" 우산에 2D 슈뮵이 다수 섞여 Shoot 'Em Up·Bullet Hell 등 무관 태그가 상위에 잡히는 노이즈 — 2장 표의 "적합도" 열로 구분. ③ 수치는 조회 시점(2026-07-03) 기준, 태그는 유저 투표로 상시 변동.

한계 및 유의

  • 시점 변동성: Steam 태그는 유저 투표 기반이라 수치는 조회일(2026-07-03) 스냅샷이다. 절대값보다 상대 순위·구간으로 해석할 것.
  • 우산 태그 노이즈: base인 Shooter(1774)에 2D 슈뮵이 다수 섞여 Shoot 'Em Up·Bullet Hell이 상위에 잡힌다. 현대 3D PVP 슈터 관점에선 이들을 제외하고 읽어야 한다.
  • AND 필터 특성: 사용률(%)은 "슈터이면서 동시에 X태그인 게임" 비율이다. 개별 태그의 Steam 전역 총량과는 다르다(예: Tactical 전역 9,392개 중 슈터 교집합은 1,697개).
  • SteamDB/SteamCharts 접근: 두 사이트의 일부 페이지는 봇 차단(403)되어 1차 수치는 Steam 스토어 공식 엔드포인트로 취득하고 태그 ID 체계만 SteamDB로 대조했다.
